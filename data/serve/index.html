Atualizar pelo GitHub

A placa baixa a versão publicada, confere placa, versão e SHA‑256 e só então instala. Nunca volta para versão anterior.

A placa procura a última versão publicada em Releases desse repositório.

Avançado: servidor próprio

Como publicar uma versão nova

  1. No PC, rode DMK.bat → Nova versão (SERVE, CONTROLE ou ambos).
  2. Escolha Publicar no GitHub. O GitHub compila as 6 placas e cria a Release.
  3. Aqui, toque em Verificar atualização e depois Instalar. Cada placa baixa só o seu arquivo.
